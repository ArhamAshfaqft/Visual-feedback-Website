# Previu website

Static marketing site for https://plugin.usepreviu.com/ hosted on Netlify.

## Development
Serve this directory with any static HTTP server. No build dependencies are required. The production entry point is index.html.

## Content
The page includes source-reviewed Free/Pro features, requirements, pricing, FAQs, SoftwareApplication and FAQPage structured data, a sitemap, and llms.txt. Fonts and images are self-hosted.

The hero uses actual product screenshots captured from an isolated sample review session and the Elementor editor. Screenshot switching and a full-size dialog are available. The walkthrough trigger is currently hidden as requested. The MP4 is a guided sequence of actual screenshots, not continuous screen recording.

Generated feature illustrations are simplified concepts, distinct from the actual product captures. The studio and its sample feedback are fictional. Local demo preparation scripts and capture records are excluded through .gitignore.

## Pricing
Annual/lifetime prices and checkout destinations are defined in index.html and script.js. Keep both synchronized. Freemius provides final totals and license terms. No purchase was made during verification; the full purchase/redemption flow still requires verification.
